Core Concepts

🔄 Classical vs. Modern

Classical ciphers use simple substitution and permutation. Modern cryptography uses complex mathematical functions with provable security properties.

🛡️ Absolute vs. Computational Security

Absolute security (like OTP) is unbreakable regardless of computing power. Computational security means decryption is infeasible given realistic constraints.

⚔️ Brute-Force vs. Cryptanalysis

Brute-force exhaustively tries all keys. Cryptanalysis exploits mathematical weaknesses in the cipher to reduce the search space dramatically.

🔑 Symmetric vs. Asymmetric

Symmetric: same key encrypts and decrypts (DES, AES). Asymmetric: public key encrypts, private key decrypts (RSA, ElGamal, DSA).
